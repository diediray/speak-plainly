# 修订模式

用户要修订稿时，交改动清单和修订稿全文，每处改动都可按编号撤销。原文有需要作者决定的歧义时，在清单对应位置标出。编辑范围与保真要求沿用[编辑方法](editing-guide.md#通用编辑方法)。

## 通读原稿

先在原稿里识别需要保留的术语、指标、引语和作者命名，以及贯穿论证的成对说法。需要保留的内容原样留下，它们所在句子的其他部分照常判断。交付从实际改动开始。

## 提哪些

通读原文和相关上下文，选真正影响阅读的改动。文笔已经自然的文章，校对实际错字和语病即可。

1. 黑话、包装词、叠在一起的比喻、只起造势作用的成分。所指能确定的，换成它实际指的普通说法，标 `等义`。造势成分删掉后读者不会少知道作者的判断、评价、条件或强调对象的，删掉，标 `删除`。
2. 上下文能确定原意，就直接改。几种读法会改变做法、结论、条件或证据范围时，正文保留原句，在对应条目标 `待确认`，说清作者需要决定什么。用户要你作判断时，给出选择和依据。要求你据判断直接改稿时，把这个选择写进修订稿。

比喻、没有固定含义的行话或生造搭配妨碍理解时，提出改法。措辞按原稿用途调整，专业稿写得自然、准确，个人文字保留个人口气。改后应更好读，并保留原来的含义和力度。

错字、漏字和明显的语病可以顺手提，标 `校对`，不补内容。

用户限定了修改范围的，只在范围内提。用户同时要求只标问题的，按只标问题处理。

下列信息原样保留，周围措辞仍可按需编辑。

- 判断强度和程度：“不会”不写成“不太会”，“唯一的办法”不写成“主要办法”。
- 否定及其范围、情态、条件、完成状态、比较关系、范围和数字。
- 作者对具体对象、影响和优先级的判断。只给前文泛泛拔高、删后意思和语气完整的句子，按编辑方法清理。
- 作者命名及其后文用法、正式术语、作为依据的引语、被讨论的措辞和要求保留原貌的讲话。整理口述材料时，按用户要求清理填充和重复，保留说话人、事实、判断和不确定程度。
- 用户指定的编辑范围：`bounded` 下不删整句、不并句、不重排。

## 怎么写每一条

- 每条覆盖一处完整改动，`原文` 逐字引用，带足上下文以便唯一定位。可以替换词句，需要合并相邻句时，一并列出原文和改文，按用户指定范围处理。同一说法出现多处，各写一条。
- `改为` 是替换 `原文` 的文字。标 `删除` 的写 `（删除）`。
- 原意、范围和力度完整保留时，标 `等义`。可能改变原意的改法放在 `待确认` 条目，写 `原文` 和需作者决定的问题，正文沿用原句。
- 各条不重叠，按原文顺序连续编号。代码、注释和代码围栏内文案的处理沿用编辑方法中的编辑范围。段号按空行分隔的段落数，标题也算一段。
- 有需要作者判断的取舍时，在该条附一行 `理由`。
- 清单没有改动也没有待确认项时，写 `没有改动`，修订稿交原文。

## 交付格式

交付前逐条核对清单，撤下改动了应保留内容的条目。核对 `待确认` 的原句仍在修订稿里。校对项有两种改法都说得通时，保留原文。

先列清单，再交修订稿全文。只把清单中已执行的改动应用到原文，待确认项及清单以外的内容原样保留。必要的来源提示和删除建议放在清单之后、正文之前。下面是格式示例。

```
## 改动清单

### 第 1 段

1. 【等义】
原文：完成了对配置的检查
改为：检查了配置

2. 【待确认】
原文：提高随访要求
待确认：指增加随访频率，还是提高随访完成率？

## 修订稿

（修订稿全文）

```

## 用户回复之后

- 撤销编号：先逐字恢复被撤销项的原文，再应用其余修改能独立成立的效果；只有无法独立保留的后续项才联动撤销，并说明受影响编号。编号不重排。
- 用户选定某个待确认项的含义后，沿用其编号，按选定的意思改写。应用后的改句可按编号撤销。
- “全部撤销”：写 `## 修订稿`，交原文。
- “全收”：接受已写入修订稿的改动，待确认项沿用原文。
- “再过一遍”：在当前修订稿上找漏掉的。用户撤销过的不再提，编号接着上次。交新增的改动清单和新的完整修订稿，格式同上。

## 例子

原文：

> 我们要打通数据的任督二脉，把用户心智焊死在平台上。这套打法铺开后，增长飞轮就转起来了。团队每周开一次会，这件事大家都很上心。今年房租压得人喘不过气，账上快见底了，老板只好勒紧裤腰带。

“打通数据的任督二脉”可改成“连通各处的数据”，“这套打法铺开后”可改成“这套做法推广后”。“把用户心智焊死在平台上”可能指让人记住平台，也可能指让人形成使用习惯。两种意思不同，正文保留原话，清单里指出需要确认的区别。

“每周开一次会”“大家都很上心”是大白话和作者评价，不提。“压得人喘不过气”“账上快见底了”“勒紧裤腰带”谁都听得懂，换成“压力大”“没钱了”“节省开支”只会更干，也不提。“这家店的翻台率掉了一半”中的“翻台率”是行业指标，按原词保留。
