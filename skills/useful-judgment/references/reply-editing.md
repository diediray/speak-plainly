# 校订答复

先补齐本轮交付，再校订文字。

## 从原文修改

局部修改取用户指向的原文或已确认版本，对所指表达做替换，再接回上下文读。保留原句的论述对象、必要条件和证据范围；抽象评述里有用的生物学关系，可以融入相邻句。需要重排时，以相关句群为范围，各证据的独特作用仍要保留。

需要独立重写时，给作者当前请求、这份原文、相关上下文与事实；旧失败稿留给选稿者比较。若争议在判断，先比较候选做法与证据，选定后再修文字。

## 自行检查或独立复核

按原问题的对象和尺度核对全文，把概括句与具体事实并读，保留当前判断、决定依据和用法；重复同一层判断时合并。同步进度将已做结果与原目标相对照，明确继续哪一步或已经完成。

校订多段说明时，先给只读校订者请求、必要事实和主体，暂留末段，请它判断用户还缺什么；再提供末段，将真正补充的事实、解释或用法接回对应位置。正文改写则连同原文核对。作者收到精确删改后，核对判断、依据和衔接再应用，直接交付成稿。

一次预测核对示范：用户问这次参考谁，已核过事前快照与实际时间。可直接答：

> 这次参考清川：它在事件前保存的预测与实际一致；晨星是在事后更新页面。

“这次”已交代判断范围。后接“尚不足以说明长期准确率”没有改变本轮选择，删去。校订建议也按原问取舍。

来源：本技能的受控预测档案测试，站点为虚构，示范将证据范围并入当前判断。

## 应用局部替换

`scripts/apply_edits.py` 只做原文匹配与替换，适合较长或多份草稿，避免重写整篇又添回废话。

原稿文件：
```json
[{"id":"reply","draft":"原答复"}]
```
编辑文件：
```json
[{"id":"reply","edits":[{"before":"完整且唯一的原文","after":"替换文字"}]}]
```
删除时after为空字符串；无需改动可用空数组。用当前材料校订，事实核对由作者和复核者完成。

```text
python scripts/apply_edits.py --cases cases.json --edits edits.json --output revised.json
```

输入输出保存在当前任务可写位置。
