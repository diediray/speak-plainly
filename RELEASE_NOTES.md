# Speak Plainly · 说人话 v1.2.0

Make a clear call. Explain what matters. Follow through.

First public release of Speak Plainly (说人话), a lightweight agent skill for useful judgments, clear answers, and continued work. The skill ID remains `useful-judgment`.

- Match requests such as “说人话”, “不要防御”, and similar requests to improve an answer, including short replies.
- Continue from existing drafts and results, and let evidence change the answer or plan.
- Cut empty caveats and repeated explanations while keeping useful facts, conditions, and relationships.
- Keep five core paragraphs, with references loaded as needed.

### Install

[Download the skill ZIP](https://raw.githubusercontent.com/diediray/speak-plainly/v1.2.0/downloads/useful-judgment-v1.2.0.zip) and place the extracted `useful-judgment` folder in your skills directory. Or ask Codex to use `$skill-installer` to install `skills/useful-judgment` from this repository.

[Download the source archive](https://github.com/diediray/speak-plainly/archive/refs/tags/v1.2.0.zip).

### Validation

Three independent agents loaded the skill without the task naming it. Two regression answers passed directly; one new combination of existing material received a local correction by its author after independent review. See EVALUATION.md in the repository.
